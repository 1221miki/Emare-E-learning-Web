# Course Edit - Quick Reference Guide for Instructors

## Accessing Course Edit

1. Go to **Instructor Dashboard** → **My Courses** tab
2. Find your course in the table
3. Click the **"Edit Info"** button
4. The Edit Course modal will open

## Edit Course Modal - Section by Section

### 1. BASIC INFORMATION
All course metadata in one place:

- **Course Title**: Main course name (required)
- **Subtitle**: Optional short description
- **Description**: Full course overview (required, min 20 characters)
- **Category**: Choose from 13 technical categories
- **Level**: Beginner, Intermediate, or Advanced
- **Language**: English, Amharic, or Afaan Oromo
- **Duration (hours)**: How long the course takes (required)
- **Status**: Displays current publication state (Draft/Published/Pending/etc.)

**💡 Tip:** All required fields are marked with an asterisk (*)

---

### 2. COURSE THUMBNAIL

Upload a professional course thumbnail image:

**What to do:**
1. Click **"Select Image"** to choose a file
2. Select a **JPG**, **PNG**, or **WebP** image (max 5MB)
3. See preview of your selected image
4. Click **"Upload"** to save to Cloudinary
5. Watch for the upload progress

**Current Thumbnail:**
- Shows the thumbnail currently saved for your course
- Updates automatically after successful upload

**Remove Thumbnail:**
- Click **"Remove Thumbnail"** to delete the current image
- Saved immediately

**File Requirements:**
- ✅ JPG/JPEG format
- ✅ PNG format
- ✅ WebP format
- ✅ Maximum 5MB file size
- ❌ PDF, GIF, or other formats not supported

**💡 Tips:**
- Use high-quality images (1280x720 minimum)
- Keep file under 2MB for faster loading
- Ensure image represents course content clearly

---

### 3. PRICING

Set course pricing and optional discount:

**Original Price (Required):**
- Set the base price of your course in ETB
- 0 = Free course
- Supports decimal values (e.g., 1500.50)

**Discount Price (Optional):**
- Set a reduced price for promotions
- Leave blank for no discount
- Must be less than original price
- System validates automatically

**Price Preview:**
When you set both prices, you'll see:
```
Original Price: 1,500 ETB
Discount Price: 1,200 ETB
Savings: 20%
```

**💡 Tips:**
- Use discounts for limited-time promotions
- Clear savings percentage helps boost sales
- Can change prices anytime before course is published

---

### 4. COURSE CONTENT

View your course curriculum structure:

**Features:**
- **See all chapters**: Chapter count shown in header
- **Lesson overview**: Each chapter shows number of lessons
- **Lesson list**: Expand to see individual lesson titles

**Example:**
```
📚 Chapter 1: Introduction
  ▪ Lesson 1: Getting Started
  ▪ Lesson 2: Basic Concepts
  ▪ Lesson 3: Setting Up

📚 Chapter 2: Advanced Topics
  ▪ Lesson 1: Deep Dive
  ▪ Lesson 2: Best Practices
```

**Quick Actions:**
- **"+ Add Chapter"**: Create new chapter
- **"+ Add Lesson"**: Add lesson to existing chapter

**No Content?**
- System shows friendly message
- Encourage you to add chapters first

**💡 Tips:**
- Organize content logically
- Aim for 3-5 chapters minimum
- 2-5 lessons per chapter recommended

## Saving Your Changes

**All Changes:**
1. Make edits to any fields
2. Upload thumbnail if desired
3. Click **"Save Changes"** button

**What Saves:**
✅ Course title, subtitle, description  
✅ Category, level, language  
✅ Duration and pricing  
✅ Discount price  
✅ Thumbnail (when uploaded)  

**What Doesn't Save:**
❌ Status (auto-managed by system)  
❌ Curriculum changes (use separate Add Chapter/Lesson buttons)

## Course Status Levels

Understand where your course is in the workflow:

| Status | Meaning | What You Can Edit |
|--------|---------|-------------------|
| **Draft** | Not yet submitted | Everything |
| **Pending Review** | Awaiting admin approval | Limited (waiting for decision) |
| **Revision Needed** | Admin requested changes | Everything |
| **Published** | Publicly available | Cannot edit (must unpublish first) |
| **Active** | Currently available for purchase | Cannot edit (must unpublish first) |
| **Archived** | Inactive/old course | Cannot edit |

**To Edit Published/Active Courses:**
1. Click course actions button
2. Select "Unpublish" to return to Draft
3. Then you can edit info again

## Common Tasks

### Task: Upload New Thumbnail
1. Open Edit Course modal
2. Go to **Thumbnail** section
3. Click "Select Image"
4. Choose a JPG/PNG/WebP file
5. See preview appear
6. Click "Upload"
7. Wait for success message
8. Click "Save Changes"

### Task: Change Course Price
1. Open Edit Course modal
2. Go to **Pricing** section
3. Update "Price" field
4. Set discount if desired
5. Review price preview
6. Click "Save Changes"

### Task: Add a Discount
1. Open Edit Course modal
2. Go to **Pricing** section
3. Enter "Discount Price" amount
4. View calculated savings %
5. Click "Save Changes"

### Task: View Course Structure
1. Open Edit Course modal
2. Scroll to **Course Content** section
3. Click arrow to expand
4. See all chapters and lessons
5. Click "Add Chapter" or "Add Lesson" to add content

### Task: Update Course Description
1. Open Edit Course modal
2. Find **Description** field in Basic Information
3. Update text
4. Keep minimum 20 characters
5. Click "Save Changes"

### Task: Change Course Language
1. Open Edit Course modal
2. Go to **Basic Information** section
3. Select new language from dropdown
4. Click "Save Changes"

## Tips for Success

### 🎯 Best Practices

**Thumbnail:**
- Use clear, professional images
- Ensure text is readable
- Match your branding
- Update when course content changes significantly

**Pricing:**
- Research competitor courses
- Use strategic discounts for promotions
- Consider course length and depth
- Round prices to psychological numbers (1,999 vs 2,000)

**Course Information:**
- Be clear and specific in descriptions
- Use appropriate category and level
- Set realistic duration estimates
- Use language students understand

**Content:**
- Organize logically (simple to complex)
- Include at least 3 chapters
- 2-5 lessons per chapter ideal
- Review curriculum before publishing

## Troubleshooting

### Problem: Thumbnail Upload Failed
**Solutions:**
- Verify file is JPG, PNG, or WebP
- Check file size (under 5MB)
- Try a different file
- Refresh page and try again

### Problem: Changes Not Saving
**Solutions:**
- Verify all required fields filled
- Check internet connection
- Look for error messages in modal
- Try again after a moment

### Problem: Can't Edit Published Course
**Solutions:**
- This is by design (prevents accidental changes)
- Click course menu and select "Unpublish"
- Course returns to Draft status
- Now you can edit
- Re-publish when done

### Problem: Discount Price Shows Error
**Solutions:**
- Ensure discount < original price
- Use smaller discount amount
- Example: Original 1500, Discount 1200 ✅

## Before Publishing

Checklist before you publish your course:

**Before You Publish:**
- [ ] Course title is clear and descriptive
- [ ] Subtitle added (optional but recommended)
- [ ] Description is detailed (min 20 chars)
- [ ] Appropriate category selected
- [ ] Correct difficulty level
- [ ] Language matches course content
- [ ] Realistic duration estimate
- [ ] Professional thumbnail uploaded
- [ ] Pricing set appropriately
- [ ] At least 3 chapters created
- [ ] Each chapter has 2+ lessons
- [ ] Course content is well-organized

**When You Publish:**
- Course becomes visible to students
- Pricing takes effect
- Students can enroll and pay
- Cannot edit basic info (must unpublish first)
- Thumbnail and pricing can be adjusted
