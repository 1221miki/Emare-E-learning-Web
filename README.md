# 🎓 Emare ELMS — E-Learning Management System

[![Node.js](https://img.shields.io/badge/Node.js-18+-green.svg)](https://nodejs.org)
[![React](https://img.shields.io/badge/React-18-blue.svg)](https://reactjs.org)
[![MongoDB](https://img.shields.io/badge/MongoDB-Atlas-green.svg)](https://mongodb.com)
[![Express](https://img.shields.io/badge/Express-4.x-lightgrey.svg)](https://expressjs.com)

A full-stack Learning Management System built for Ethiopian tech education. Instructors create and publish courses with Bunny Stream video lectures and Bunny Storage PDF resources. Students enroll, learn, and earn verifiable certificates.

---

## 🚀 Quick Start

### Prerequisites

- Node.js 18+
- npm 9+
- MongoDB Atlas connection string (already configured in `backend/.env`)

### 1. Clone & Install

```bash
# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../client
npm install
```

### 2. Start the Backend

```bash
cd backend
npm run dev
# Runs on http://localhost:5000
```

### 3. Start the Frontend

```bash
cd client
npm run dev
# Runs on http://localhost:5173
```

## 📦 Media & Storage

| Content Type | Storage          | URL Pattern                                        |
|--------------|------------------|----------------------------------------------------|
| Videos       | Bunny Stream     | `https://iframe.mediadelivery.net/embed/LIB/GUID`  |
| PDFs / Files | Bunny Storage    | Served via backend proxy `/api/pdf-proxy/*`        |
| Images       | Cloudinary       | `https://res.cloudinary.com/...`                   |
| Avatars      | Cloudinary       | `https://res.cloudinary.com/...`                   |

> **PDF CDN note:** PDFs are proxied through the backend (`GET /api/pdf-proxy/path/to/file.pdf`) to avoid reliance on the Bunny Pull Zone CDN hostname. Files are streamed directly from Bunny Storage.

## 🎓 Certificate System

### Certificate ID Format

```
EMARE-CERT-YYYY-NNNNNN
```

Example:
```
EMARE-CERT-2026-000001   ← Student A, Python Course
EMARE-CERT-2026-000002   ← Student B, Python Course
EMARE-CERT-2026-000003   ← Student C, React Course
```

### Key Properties

- **Globally unique** — every certificate has a different ID
- **Sequential** — generated by atomic MongoDB `$inc` counter (race-condition safe)
- **Persistent** — re-downloading always shows the same ID
- **Verifiable** — public endpoint: `/verify-certificate/:certificateId`
- **One per student per course** — enforced by compound unique DB index

### Certificate Verification (Public)

Anyone can verify a certificate without logging in:

```
https://your-domain.com/verify-certificate/EMARE-CERT-2026-000001
```

Or via API:
```
GET /api/certificates/verify/EMARE-CERT-2026-000001
```

## 🛣️ API Reference

### Authentication

```
POST /api/auth/register          Register new user
POST /api/auth/login             Login
POST /api/auth/logout            Logout
GET  /api/auth/me                Current user profile
POST /api/auth/forgot-password   Send reset email
POST /api/auth/reset-password    Set new password
```

### Courses

```
GET    /api/courses              List published courses
GET    /api/courses/:id          Course detail + curriculum
POST   /api/courses              Create course (Instructor)
PUT    /api/courses/:id          Update course (Instructor)
PATCH  /api/courses/:id/submit   Submit for review
PATCH  /api/courses/:id/approve  Approve (Admin)
PATCH  /api/courses/:id/publish  Publish (Admin)
```

### Certificates

```
POST /api/certificates/issue/:courseId   Issue certificate (Student)
GET  /api/certificates/my               List my certificates (Student)
GET  /api/certificates/check/:courseId   Check eligibility (Student)
GET  /api/certificates/:id/download      Download PDF (Student)
GET  /api/certificates/verify/:certId   Verify certificate (PUBLIC)
GET  /api/certificates/admin/all         All certificates (Admin)
```

### Payments

```
POST /api/payments/initiate        Initiate Chapa payment
GET  /api/payments/chapa/verify/:tx_ref  Verify payment
POST /api/payments/coupon          Validate coupon code
```

### Subscriptions (Newsletter)

```
GET  /api/subscriptions/status              Check subscription status
POST /api/subscriptions/status/check-email  Email-based status check
POST /api/subscriptions/discount            Subscribe for discount coupon
```

### PDF Proxy

```
GET /api/pdf-proxy/*path    Stream PDF from Bunny Storage (authenticated)
```

## 🔒 Security

- JWT authentication via HTTP-only cookies
- Role-based access control (Admin / Instructor / Student)
- Rate limiting on auth and subscription endpoints
- Server-side coupon validation (discount never trusted from frontend)
- Certificate IDs generated server-side — frontend cannot forge them
- PDF proxy requires authentication
- Device fingerprinting (SHA-256 of IP + UA) for subscription abuse prevention

## 🧪 Test Scenarios

### Certificate Uniqueness

| Student | Course          | Expected Certificate ID     |
|---------|-----------------|----------------------------|
| A       | Python          | EMARE-CERT-2026-000001      |
| B       | Python          | EMARE-CERT-2026-000002      |
| C       | React           | EMARE-CERT-2026-000003      |
| A       | Python (again)  | EMARE-CERT-2026-000001 (same) |

### Verification

```bash
# Valid certificate
GET /api/certificates/verify/EMARE-CERT-2026-000001
→ { valid: true, data: { certificateId, studentName, course, issueDate, ... } }

# Invalid certificate
GET /api/certificates/verify/FAKE-ID-0000
→ { valid: false, message: "Certificate not found." }
```
